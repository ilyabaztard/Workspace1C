# Workspace 1C 1.0.0.82

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.82

### Добавлено

- **Серверы 1С: колонки по содержимому заголовка, горизонтальная прокрутка и сохранение размеров колонок по вкладкам (issue #75, Windows и Linux)** — колонки вкладок «Сеансы»/«Соединения»/«Блокировки»/«Рабочие процессы» получают по умолчанию ширину под заголовок и стрелку сортировки, у таблиц включена горизонтальная прокрутка; размеры колонок каждой вкладки сохраняются отдельно и переживают закрытие программы ([`ServerMonitorColumnWidthsStore.cs`](Workspace1C/Services/ServerMonitorColumnWidthsStore.cs), [`ServerMonitorWindow.xaml`](Workspace1C/Views/ServerMonitorWindow.xaml), [`ServerMonitorWindow.Avalonia.cs`](Workspace1C/Views/ServerMonitorWindow.Avalonia.cs), [`AppSettings.cs`](Workspace1C/Models/AppSettings.cs)). Покрыто тестами `ServerMonitorColumnWidthsTests`, `Issue75ServerMonitorColumnsTests`.
- **Мультивыделение в «Серверах 1С»: завершение сеансов и разрыв соединений несколькими строками разом (issue #72, Windows и Linux)** — групповое выделение на вкладках «Сеансы»/«Соединения», кнопки действуют на все выбранные строки, сводка «N из M» в статус-строке ([`ServerMonitorViewModel.cs`](Workspace1C/ViewModels/ServerMonitorViewModel.cs), [`ServerMonitorWindow.xaml`](Workspace1C/Views/ServerMonitorWindow.xaml)). Покрыто тестами `ServerMonitorViewModelTests` (+7).

### Исправлено

- **Публикация баз: inline-комментарии и fallback по Include-шаблонам (issue #63, Windows и Linux)** — при разборе конфигов Apache отбрасываются inline-комментарии `# ...` в значениях директив, `Include` с `${VAR}` раскрываются по полному Define-графу; в списке ConfTargets только фактически используемый файл алиасов (`1c8Aliases27.conf`), корректно пересчитываются каталог `…/htdocs/27` и порт/URL `8027` ([`ApacheConfIncludeParser.cs`](Workspace1C/Services/ApacheConfIncludeParser.cs), [`WebPublishViewModel.cs`](Workspace1C/ViewModels/WebPublishViewModel.cs)). Покрыто тестами `ApacheConfIncludeParserTests`, `ApacheInstanceDetectorTests`, `Apache27ConfRegressionTests`, `WebPublishIssue63Tests` (+9).
- **Запуск х86 из другого места (issue #73, Windows и Linux)** — явная разрядность базы «32» имеет приоритет над глобальной политикой «X64, если не указано», пользовательские каталоги платформы участвуют в поиске 32-битной версии ([`OneCLauncher.cs`](Workspace1C/Services/OneCLauncher.cs), [`OneCLauncher.Linux.cs`](Workspace1C/Services/OneCLauncher.Linux.cs)). Покрыто тестами `OneCLauncherArchitectureTests` (+7).
- **Формы и элементы: единый аудит минимальных размеров всех окон (issue #55, Windows и Linux)** — каждому окну заданы MinWidth/MinHeight, при которых содержимое не обрезается; закрыт обход минимумов в «Выборе баз», высота монитора серверов увеличена до 560 ([`BaseSelectionWindow.axaml`](Workspace1C/Views/BaseSelectionWindow.axaml), [`ServerMonitorWindow.xaml`](Workspace1C/Views/ServerMonitorWindow.xaml)). Покрыто тестами `Issue55WindowLayoutTests`, `Issue55AdaptiveLayoutTests` (+6).
- **Ширина окна «Настройки» (issue #71, Windows и Linux)** — политика «минимальные размеры + запрет сужения»: «Настройки» — 960×720, «Настройка информационной базы» — 760×780, горизонтальная прокрутка вкладок отключена ([`SettingsWindow.xaml`](Workspace1C/Views/SettingsWindow.xaml), [`ConnectionSettingsWindow.xaml`](Workspace1C/Views/ConnectionSettingsWindow.xaml)). Покрыто тестами `Issue71SettingsWindowLayoutTests` (+8).
- **Удаление из кластера (issue #69, Windows и Linux)** — разрыв соединений и сеансов перед каждым `infobase drop`, галочка блокировки регламентных заданий при первом запросе, копирование флагов блокировок при миграции ([`ServerMonitorViewModel.cs`](Workspace1C/ViewModels/ServerMonitorViewModel.cs), [`ClusterMigrationService.cs`](Workspace1C/Services/ClusterMigrationService.cs)). Покрыто тестами `ServerMonitorViewModelTests` (+7), `Issue69DropRetryWindowLayoutTests` (+2), `ClusterMigrationViewModelTests` (+2).
- **Миграция баз (issue #41, Windows и Linux)** — имя первой базы видно сразу, список сортируется по имени, окно не закрывается по завершении (накапливающийся результат) ([`ClusterMigrationViewModel.cs`](Workspace1C/ViewModels/ClusterMigrationViewModel.cs), [`ClusterMigrationWindow.xaml.cs`](Workspace1C/Views/ClusterMigrationWindow.xaml.cs)). Покрыто тестами `ClusterMigrationViewModelTests`, `Issue41WindowLayoutTests` (+5).
- **Акцентные цвета и контрастность: единый контракт кнопок (issue #26, Windows и Linux)** — `ModernButton`/`SecondaryButton`/`DangerButton` с контрастным `TextOnAccentBrush`, убраны жёсткие цвета, обновлено около 50 окон в обеих платформах ([`LightTheme.xaml`](Workspace1C/Themes/LightTheme.xaml), [`DarkTheme.xaml`](Workspace1C/Themes/DarkTheme.xaml), [`Controls.axaml`](Workspace1C/Themes/Controls.axaml)). Покрыто тестами `Issue26ButtonUniformityTests` (+9).

Полный прогон тестов зелёный (4635 тестов).
