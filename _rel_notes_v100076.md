# Workspace 1C 1.0.0.76

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

### Добавлено

- **Удаление информационной базы из кластера: подсказки по типовым ошибкам rac и
  кнопка «Завершить сеансы и повторить» (issue #69, Windows и Linux)** — при неудачном
  «infobase drop» текст ошибки классифицируется: защищённая ИБ/права, активные
  сеансы/соединения, сервер СУБД, неизвестно; диалог повтора показывает локализованную
  подсказку по типу ошибки. При занятой базе появляется кнопка **«Завершить сеансы и
  повторить»**: активные сеансы и соединения именно этой базы завершаются, и удаление
  повторяется с кредами администратора ИБ. Повторные неудачи помечаются «Повторная
  попытка удаления не удалась: …». Покрыто тестами `ServerMonitorViewModelTests`,
  `Issue69DropRetryWindowLayoutTests`.

### Изменено

- **Публикация на Apache: парсер доработан по реальным конфигам пользователя
  (issue #63, Windows и Linux)** — относительный `-f conf\httpd27.conf` резолвится от
  ServerRoot; Include-граф раскрывается по всему дереву, `Define` из любого файла
  видны независимо от порядка; `DocumentRoot`/`Listen` ищутся в любом файле графа;
  неразрешённые `${...}` в UI не попадают. Регресс-тесты `Apache27ConfRegressionTests`
  на реальных конфигах.

- **Миграция баз: имя группы и дедупликация (issue #41, Windows и Linux)** — порт в
  имени группы «Хост - Кластер (порт)» добавляется только при нестандартном значении
  (не 1540/1541); повторная миграция в тот же приёмник не создаёт группу-дубликат;
  после исключения миграции статусы приёмника обновляются автоматически; полоса
  прогресса Avalonia-окна растянута на всю ширину.

### Исправлено

- **Меню трея: иконка группы больше не обрезается справа (issue #62, Windows и Linux)** —
  новый `TrayMenuIconFitter` вписывает геометрию иконки в ячейку 20×20 (масштаб +
  сдвиг + центрирование, глиф ~90% ячейки); превью редактора совпадает с применением.
  Покрыто тестами `TrayMenuIconFitTests`.

- **Тёмная тема: подписи полей форм и раскрыватели деревьев (issue #61, Windows и
  Linux)** — явный стиль `FieldLabel` с `FormLabelBrush` в окнах «Новый сервер»,
  «Свойства информационной базы», «Изменение параметра запуска», «Создание ИБ» (WPF);
  подписи «Командная строка»/итоговое поле в окнах выбора и правки скрипта переведены
  на `FormLabelBrush` и стиль `ModernTextBox`; деревья редакторов структуры меню — на
  `ModernTreeViewItem`; Avalonia-подписи — на `FormLabelBrush`. Расширены тесты-стражи
  `ThemeFormLabelTests`/`Issue61TitleColorsTests`/`Issue61DarkPaletteAuditTests`.

Подробности — в [CHANGELOG.md](https://github.com/sivatorov/Workspace1C/blob/main/CHANGELOG.md).
