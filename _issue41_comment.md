Исправлено в версии 1.0.0.71 (Windows и Linux) по замечаниям из комментария: (1) поле **«Имя БД»** убрано с формы миграции (добавлялось в 1.0.0.70) — [`ClusterMigrationWindow.xaml`](Workspace1C/Views/ClusterMigrationWindow.xaml) и [`ClusterMigrationWindow.axaml`](Workspace1C/Views/ClusterMigrationWindow.axaml); из VM удалены свойство `DbName`, автозаполнение из первой базы и значение поля из запроса ([`ClusterMigrationViewModel.cs`](Workspace1C/ViewModels/ClusterMigrationViewModel.cs)); (2) имя БД переносится **автоматически** из источника: [`ClusterMigrationService.BuildCreateRequest`](Workspace1C/Services/ClusterMigrationService.cs) — приоритет у `DbName` базы из «infobase summary list»; если rac не вернул db-name (выяснено: отдельные версии rac не выводят колонку/ключ db-name в summary list, см. [`RacOutputParser.ToInfobaseSummaries`](Workspace1C/Services/RacOutputParser.cs)) — используется имя информационной базы (при создании ИБ сервер 1С по умолчанию именует БД в СУБД так же, как ИБ), поэтому fallback работает без лишних запросов; проверка/ошибка `DbNameEmptyFormat` удалена — DbName у запроса всегда непуст (иначе общая ошибка создания); (3) сводка «Выделено: N из M · будет перенесено: N» и кнопки «Выделить все»/«Снять все» перенесены в строку сразу под списком баз, над галочками-опциями ([`ClusterMigrationWindow.xaml`](Workspace1C/Views/ClusterMigrationWindow.xaml), [`ClusterMigrationWindow.axaml`](Workspace1C/Views/ClusterMigrationWindow.axaml); Avalonia-хост `BulkHost` — [`ClusterMigrationWindow.Avalonia.cs`](Workspace1C/Views/ClusterMigrationWindow.Avalonia.cs)). Ключи локализации `ClusterMigration.DbName` и `ClusterMigration.Error.DbNameEmptyFormat` удалены из ru/en (не используются).

Добавлены юнит-тесты: `ClusterMigrationServiceTests` (fallback `db-name` = имя ИБ при пустом имени у rac; приоритет собственного db-name источника; крайний случай пустой записи), `ClusterMigrationViewModelTests` (успешный перенос без поля — в rac уходит имя ИБ, когда rac не вернул db-name; DbName запроса всегда непуст; регресс передачи Dbms/DbServer), `Issue41WindowLayoutTests` (в разметке обеих платформ нет поля «Имя БД», сводка и кнопки выделения расположены над опциями; ключи локализации удалены).

Реализовано на обеих платформах.
