# Workspace 1C 1.0.0.90

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.90

### Добавлено

- **Заметки к базе (п.8 «Заметки к базе», Windows и Linux)** — markdown-карточка у каждой
  базы (для кого база, контакты, особенности обновления) и зашифрованный раздел
  паролей/ключей внешних сервисов:
  - окно «Заметки…» в контекстном меню базы: редактор markdown с предпросмотром
    ([`MarkdownRenderer.cs`](Workspace1C/Services/MarkdownRenderer.cs)), список секретов
    «имя → значение» с показом по кнопке «глаз»;
  - хранилище [`NoteStore.cs`](Workspace1C/Services/NoteStore.cs) — файл
    `infobase_notes.json` в каталоге данных профиля; привязка по ключу базы
    (ID 1С или имя) — заметка сохраняется при импорте/переименовании;
  - шифрование [`NoteCrypto.cs`](Workspace1C/Services/NoteCrypto.cs): **Windows — DPAPI**
    текущего пользователя (ключ на диск не пишется); **Linux — AES-256-GCM** ключом
    профиля (`notes_crypto.key`, права 0600). Секреты НЕ логируются и не выводятся в
    открытом виде; при переносе между ПК — «зашифровано, ключ недоступен» без падения;
  - заметки включены в **поиск** (палитра команд Ctrl+K и фильтр дерева) и в
    **HTML-отчёт** — новая секция «Заметки» с безопасным рендером markdown
    ([`HtmlReportExporter.cs`](Workspace1C/Services/HtmlReportExporter.cs));
  - **перенос через общие списки/JSON**: снимок списка баз включает заметки
    (markdown-карточки и имена секретов; значения не переносятся — они зашифрованы
    ключом исходной машины), при импорте локальная заметка с тем же ключом сохраняется.

### Тесты

- [`InfobaseNoteTests.cs`](Workspace1C.Tests/InfobaseNoteTests.cs): AES-GCM round-trip
  и отказ при неверном ключе, `NoteCrypto` (префиксы `v1:`/`v2:`, статус «ключ
  недоступен», статусные ключи локализации), `NoteStore`
  get/save/delete/search/purge/import (перенос заметок JSON-снимком без значений
  секретов), включение заметок в фильтр палитры команд, секция «Заметки» в
  HTML-отчёте (включая экранирование пользовательского ввода), пункт меню «Заметки…»
  в каталоге и стандартной компоновке.

Всего в релизе **4795** юнит-тестов (все проходят на Windows; Linux-сборка — без ошибок).
