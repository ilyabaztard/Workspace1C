Исправлено в версии 1.0.0.71 (Windows и Linux).

**Часть 1 — читаемые поля ввода.** Поля в карточках больше не сливаются с фоном: введена глобальная кисть `InputBackgroundBrush` (светлая тема — `#E8EDF3` на фоне карточки `#FFFFFF`, тёмная — `#273548` на `#1E293B`), объявленная в палитрах [`ColorScheme.cs`](Workspace1C/Models/ColorScheme.cs) (по умолчанию и в генерируемых схемах), в WPF-темах [`LightTheme.xaml`](Workspace1C/Themes/LightTheme.xaml)/[`DarkTheme.xaml`](Workspace1C/Themes/DarkTheme.xaml) и в Avalonia [`LightTheme.axaml`](Workspace1C/Themes/LightTheme.axaml)/[`DarkTheme.axaml`](Workspace1C/Themes/DarkTheme.axaml)/[`Controls.axaml`](Workspace1C/Themes/Controls.axaml). Стили `ModernTextBox`, `ModernComboBox` и неявный `PasswordBox` (WPF Light+Dark), а также `ModernTextBox`/`ModernComboBox`/`ModernPasswordBox` (Avalonia) используют `InputBackgroundBrush` вместо `CardBackgroundBrush`; поля, собираемые кодом через [`WpfUi.BoundTextBox`](Workspace1C/Views/WpfUi.cs)/`BoundCombo`, тоже берут кисть ввода из темы. Пять полей окна публикации (имя, каталог, конфиг, строка соединения и список серверов) и остальные окна с `Card` теперь читаемы в обеих темах; поле поиска (`SearchTextBox`) намеренно не тронуто.

**Часть 2 — инстансы Apache.** Окно «Публикация на веб-сервере» теперь обнаруживает установленные инстансы Apache вместо фиксированного {IIS, Apache 2.4, Apache 2.2}:
- [`Models/ApacheInstance.cs`](Workspace1C/Models/ApacheInstance.cs) — модель инстанса (имя службы, описание, ServerRoot/Htdocs, вид 2.4/2.2, include-файлы и include-каталоги);
- [`Services/ApacheConfIncludeParser.cs`](Workspace1C/Services/ApacheConfIncludeParser.cs) — чистый разбор директив `Include`/`IncludeOptional` (относительные пути резолвятся относительно каталога конфига, wildcard `*` помечается как каталог);
- [`Services/ApacheInstanceDetector.cs`](Workspace1C/Services/ApacheInstanceDetector.cs) (+ `.Windows.cs`/`.Linux.cs`) — Windows: перебор служб httpd по реестру с разбором `ImagePath` (`-d ServerRoot`, `-f conf`, конфиг по умолчанию `ServerRoot\conf\httpd.conf`, htdocs `ServerRoot\htdocs`); Linux: `apache2ctl -V`/`httpd -V` (HTTPD_ROOT/SERVER_CONFIG_FILE) + `-S` (DocumentRoot), fallback-пути `/etc/apache2/apache2.conf` и `/var/www`. Если инстансы не найдены — список пуст и окно использует прежние `SuggestApacheConf`/`SuggestPhysicalDirectory`;
- [`WebPublishViewModel.cs`](Workspace1C/ViewModels/WebPublishViewModel.cs): список серверов строится из инстансов («IIS» на Windows + «Apache 2.4 — <служба>», fallback-пункт «Apache 2.4» при пустом списке); выбор инстанса автозаполняет `ApacheConfPath` и каталог публикации; вторым ComboBox выбран конфиг-файл для webinst — основной конфиг или include-файл (`ConfTargets`/`ConfTargetIndex`). Логика публикации (`ServerIndex`/`IsApache`/`BuildRequest`) сохранена, `WebPublishService.Validate` по-прежнему принимает непустой путь, в том числе include-файл.

Локализация новых подписей — ru/en: `WebPublish.ApacheInstanceOption`, `WebPublish.ApacheDefaultOption`, `WebPublish.ConfTarget`, `WebPublish.ConfTargetMain`, `WebPublish.ConfTargetInclude`.

Добавлены юнит-тесты: `Issue63InputBackgroundBrushTests` (разметочные проверки Controls.axaml/LightTheme/DarkTheme — поля используют `InputBackgroundBrush`, а не `CardBackgroundBrush`; палитра различает фон поля и фон карточки), `ApacheConfIncludeParserTests`, `ApacheInstanceDetectorTests` (Windows `-d`/`-f`, Linux `apache2ctl -V`), `WebPublishViewModelTests` (выбор инстанса подставляет конфиг/каталог, выбор include-файла, validate include-пути). Проект собран для Windows (WPF) и Linux (Avalonia); полный прогон тестов зелёный.
