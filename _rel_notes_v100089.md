# Workspace 1C 1.0.0.89

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.89

### Добавлено

- **История размеров баз по дням (п.7 «История размеров баз и прогноз диска», Windows и
  Linux)** — дневные снимки размеров файловых ИБ и каталогов копий хранятся в
  `size_history.json` (каталог данных профиля) с ротацией по глубине настройки
  `SizeHistoryMaxDays` (по умолчанию 365 дней):
  - модель [`SizeSnapshotEntry.cs`](Workspace1C/Models/SizeSnapshotEntry.cs): день (UTC),
    id и имя базы, размер ИБ, объём каталога копий, свободное место на диске копий;
  - хранилище [`SizeHistoryStore.cs`](Workspace1C/Services/SizeHistoryStore.cs): один
    снимок на базу в сутки (повтор в тот же день обновляет), ротация старых записей,
    фильтры по периоду и агрегаты;
  - сбор снимков: при штатных замерах размеров (`MainViewModel.Tools`) и по расписанию
    мониторинга (`ServerAlertsService`), не чаще раза в день на базу
    ([`SizeSnapshotCollector.cs`](Workspace1C/Services/SizeSnapshotCollector.cs)).
- **График роста в «Центре обслуживания»** — новая секция «История размеров»:
  - «Топ баз по росту» за период и выбор базы (также по одиночному клику строки таблицы);
  - период 7/30/90 дней; простой линейный график на панели **без внешних графических
    библиотек** (WPF — `Canvas`+`Polyline`, Avalonia — `Canvas`+`Polyline`);
  - прогноз роста выбранной базы («+0,3 ГБ в день», последний замер) и **прогноз
    «диск под копиями закончится примерно через N дней»** — линейная экстраполяция
    (метод наименьших квадратов) по снимкам каталога копий, диапазон по разбросу точек
    (R²), дата заполнения ([`DiskForecastService.cs`](Workspace1C/Services/DiskForecastService.cs)).
- **Оповещение «Диск под копиями закончится через N дней»** — проверка в
  `ServerAlertsService` на каждом цикле мониторинга: порог `DiskForecastThresholdDays`
  (0 — отключено) из окна «Уведомления в Telegram и по email» (новая секция «Прогноз
  диска под копиями»); защита от повторов — не чаще раза в
  `DiskForecastAlertRepeatDays` дней на диск; доставка через существующий
  `NotificationDispatcher` (системное уведомление, Telegram, email).

### Тесты

- [`SizeHistoryTests.cs`](Workspace1C.Tests/SizeHistoryTests.cs): запись/чтение, замена
  снимка того же дня, «не чаще раза в день», ротация (чистая функция и на сохранении),
  фильтры периода, агрегаты.
- [`DiskForecastTests.cs`](Workspace1C.Tests/DiskForecastTests.cs): линейная
  аппроксимация (точная линия, шум → R²<1, вырожденные входы), темп роста (рост / ноль /
  спад), прогноз «дней до заполнения» (базовый случай и краевые: нет свободного места,
  нет данных, 0/1 точка, скорость 0), подавление повторов и порог (0 — отключено).

Всего в релизе **4776** юнит-тестов (все проходят на Windows; Linux-сборка — без ошибок).
