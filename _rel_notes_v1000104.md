# Workspace 1C 1.0.0.104

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.104

### Добавлено

- **Настройка логирования по направлениям (issue #80 «Настройка логирования»,
  Windows и Linux).** Информационные записи (INFO) в общем журнале приложения
  (`logs/app-YYYYMMDD.log`) теперь группируются по направлениям и включаются
  отдельно. По умолчанию все направления ВЫКЛЮЧЕНЫ; ошибки (ERROR) и
  предупреждения (WARN) пишутся всегда — важные сбои остаются видимыми без
  настройки.

- **Вкладка «Логирование» в окне «Настройки»** (последняя, перед «О программе»,
  на обеих платформах): список «как для колонок» — галочка, название и пояснение
  каждой категории; группы «Направления» и «Диагностика (отладочные флаги
  trace.json)».

- **Общий выключатель «CM_ON»** — включает все направления логирования разом
  (выключен по умолчанию; пока он выключен, INFO направлений не пишется даже
  у включённой категории).

- **Направления issue #80 (все по умолчанию выключены):**
  `CM_MAIN_WINDOW` (запуск/завершение приложения, инициализация MainViewModel
  и главного окна), `CM_RAC` (все события клиента RAC/оснастки — много данных,
  после полировки обычно отключается), `CM_BASE_RUN` (запуск баз), `CM_BACKUP`
  (создание резервных копий), `CM_IBASES` (импорт/экспорт ibases.v8i),
  `CM_JOBS` (задания по расписанию), `CM_THEMES` (применение тем).

- **Группа «Диагностика»** — существовавшие отладочные флаги `trace.json`
  (`CM_COLUMNS`, `CM_MENUCLICK`, `CM_MENUCLOSE`, `CM_REDIRECT`, `CM_TREESWITCH`,
  `CM_TREESWITCH_FLUSH`, `CM_REVEAL`, `CM_CLUSTERIMPORT`, `CM_UPDATES`) — теперь
  все места логирования видны и управляются из одного окна.

- **Где хранятся настройки.** Изменения вкладки попадают в `trace.json` (рядом с
  `settings.json` активного профиля) через
  [`TraceFlags.SaveCategorySettings`](Workspace1C/Services/TraceFlags.cs) и
  применяются без перезапуска — конфиг перечитывается при изменении файла.
  INFO-записи помечаются префиксом `[CM_…]` для фильтрации в журнале
  ([`Log`](Workspace1C/Services/Log.cs),
  [`LogCategory`](Workspace1C/Services/LogCategory.cs)).

### Тесты

- [`LoggingCategoriesTests.cs`](Workspace1C.Tests/LoggingCategoriesTests.cs):
  +12 — категории и значения по умолчанию (все выключены, ERROR/WARN всегда),
  гейт «CM_ON + категория», явный `false` не перекрывается env, сохранение и
  чтение `trace.json` (round-trip, неизвестные флаги игнорируются), разметка
  вкладки «Логирование» (WPF XAML и Avalonia) и локализация ru/en. Всего в
  проекте более 4 900 юнит-тестов.
