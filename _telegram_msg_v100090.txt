Вышел Workspace 1C 1.0.0.90 (Windows и Linux):

• «Заметки к базе» (п.8): markdown-карточка у каждой базы и зашифрованный раздел паролей/ключей внешних сервисов.
• Окно «Заметки…» в контекстном меню базы: редактор markdown с предпросмотром и список секретов с показом по кнопке «глаз».
• Хранение — infobase_notes.json рядом с настройками, привязка по ID базы (заметка сохраняется при импорте/переименовании).
• Шифрование: Windows — DPAPI пользователя, Linux — AES-256 ключом профиля. Секреты не логируются; при переносе между ПК — «зашифровано, ключ недоступен» вместо значения.
• Заметки участвуют в поиске (палитра команд Ctrl+K и фильтр дерева) и попадают в HTML-отчёт нового удобного формата (секция «Заметки» с рендером markdown).
• JSON-перенос списка баз теперь включает заметки (карточки и имена секретов; значения привязаны к ключу исходной машины).

Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.90
