# Workspace 1C 1.0.0.92

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.92

### Добавлено

- **Тестовый контур одной кнопкой (п.10 «Развернуть тестовую копию», Windows и Linux)** —
  связанный сценарий подготовки тестовой копии «из прода» без ручных шагов:
  - пункт «Развернуть тестовую копию…» в контекстном меню базы (подменю
    «Администрирование», `ContextMenuCommandKind.TestDeploy`, обе платформы);
  - мастер-окно ([`TestDeployWindow.cs`](Workspace1C/Views/TestDeployWindow.cs) WPF,
    [`TestDeployWindow.Avalonia.cs`](Workspace1C/Views/TestDeployWindow.Avalonia.cs) Avalonia;
    общая ViewModel — [`TestDeployViewModel.cs`](Workspace1C/ViewModels/TestDeployViewModel.cs)):
    имя тестовой базы (по умолчанию «Тест: <имя>»), режим **сервер 1С** (создание через
    `CREATEINFOBASE`) или **файловая база**, параметры сервера/СУБД, **движок выгрузки**
    («Конфигуратор» / ibcmd), отключение регламентных заданий, смена заголовка/цвета,
    группа «Тест» (автосоздание), «обновить существующую копию», расписание
    «каждый понедельник», предпросмотр плана шагов и журнал прогресса;
  - оркестратор [`TestDeployService.cs`](Workspace1C/Services/TestDeployService.cs):
    шаги «выгрузка .dt → создание/обновление → загрузка копии (RestoreIB) → выключение
    регламентов ([`ScheduledJobsService`](Workspace1C/Services/ScheduledJobsService.cs),
    1.0.0.85) → заголовок/цвет → группа „Тест"»; **повторное развёртывание разумное**:
    копия уже есть — обновляется данными, нет — создаётся; ошибка шага — понятным
    сообщением, без секретов в журнале;
  - чистый план [`TestDeployPlanner.cs`](Workspace1C/Services/TestDeployPlanner.cs):
    имя/поиск существующей копии, решение по группе «Тест» (корневая, отличительный цвет),
    последовательность шагов, валидация;
  - сценарии хранятся в `test_deploy.json` каталога профиля
    ([`TestDeployStore.cs`](Workspace1C/Services/TestDeployStore.cs));
  - **задание по расписанию** нового типа «Развернуть тестовую копию»
    (`ScheduledTaskKind.TestDeploy`): «каждый понедельник обновлять тест из прода» —
    стандартное окно «Задания по расписанию» (список «Сценарий» показывает тест-сценарии);
    результат последнего запуска пишется в сценарий (без секретов).
- Релиз завершает серию пп. 4–10 (задачи 1–6 → 1.0.0.86–1.0.0.91).

### Тесты

- [`TestDeployTests.cs`](Workspace1C.Tests/TestDeployTests.cs): построение имени тестовой
  базы (префикс «Тест: », без дублей), поиск существующей копии (точное имя и
  переименованные «Тест: …» копии), создание группы «Тест» (существующая/новая/отключённая),
  план шагов «создать» vs «обновить», валидация параметров (сервер/файл/СУБД/существующая
  копия при выключенном обновлении), round-trip `test_deploy.json`, сборка сценария
  из ViewModel (режим, движок, дни недели). Обновлены ожидания тестов контекстного меню
  под новый пункт. Всего **4849** юнит-тестов (все проходят на Windows; Linux — 0 ошибок).
